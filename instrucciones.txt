(linux, debian 12)

1. Descargar del campus virtual p2data.zip
	Suponemos que queda en el directorio $HOME/Descargas

2. Descomprimirlo
	cd $HOME/Descargas
	unzip p2data

3. Tenemos que crear un entorno virtual python
	(sudo apt-get update)
	(sudo apt-get upgrade)
	(sudo apt-get install python3-venv)
	python3 -m venv tmp
	
4. Activarlo
	source ./tmp/bin/activate

5. Instalar librerías python necesarias
	pip install mediapipe

6. Probar
	cd p2data
	python ejemplo0.py
	python ejemplo1.py
	python ejemplo2.py

7. Instalar librerías python necesarias
	pip install deepface
	pip install tf-keras

8. Probar
	python ejemplo4.py

si cuando se ejecuta

    python ejemplo0.py

puede verse

    QFontDatabase: Cannot find font directory /home/marcos/usr/docencia/cursos/curso 2025-26/rds/p2/tmp/lib/python3.11/site-packages/cv2/qt/fonts.
Note that Qt no longer ships fonts. Deploy some (from https://dejavu-fonts.github.io/ for example) or switch to fontconfig.

la solución está en crear el directorio y copiar algunas fuentes

    mkdir -p "/home/marcos/usr/docencia/cursos/curso 2025-26/rds/p2/tmp/lib/python3.11/site-packages/cv2/qt/fonts"
    cp /usr/share/fonts/truetype/dejavu/*.ttf "/home/marcos/usr/docencia/cursos/curso 2025-26/rds/p2/tmp/lib/python3.11/site-packages/cv2/qt/fonts/"
